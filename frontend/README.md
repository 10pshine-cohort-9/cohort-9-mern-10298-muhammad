# NoteMaster Pro - Frontend

This is the frontend portion of the NoteMaster Pro application, built with React and Vite.

## Setup Instructions

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Application Routes

- `/login`: The authentication screen (Login and Sign-up).
- `/dashboard`: The main application dashboard where notes are listed.

**Note:** Authentication and dashboard data are currently simulated using local component state. They will be connected to the Node.js/MySQL backend in upcoming feature branches.
